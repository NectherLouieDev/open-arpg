# Player sprite asset

The Rogue PNG frames in this folder come from **Top-Down Character Roster Lite** by riekahq.

- Source: https://riekahq.itch.io/topdown-roster-lite
- The author permits personal and commercial game use; attribution is appreciated but not required.
- The pack is disclosed as AI-assisted artwork reviewed by a person.

The project currently uses the Rogue's `idle`, `walk`, and `act` frame files. The single `act` sequence is reused for Range, Light, Heavy, and Casting, with category-specific playback timing. The source pack does not provide four distinct attack/cast sequences. Its idle frames are shared rather than direction-specific, so the directional idle poses use the first frame of each directional walk strip.
